# Know Your Hidden Secrets and Future

Astrology website starter with customer and admin portals, readings, dashboards, and a direct messaging interface.

## Production integrations
- Secure database and server-side authentication
- Password hashing, sessions and OTP verification
- Verified astrology/Kundli engine
- Payment gateway
- Email/SMS/WhatsApp provider
- Server-side admin authorization
- Privacy, consent, HTTPS and environment secrets

Never place provider API keys in client-side JavaScript.
